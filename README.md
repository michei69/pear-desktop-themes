# Themes for [🍐 Pear Desktop](https://github.com/michei69/pear-desktop)

Note: These themes are only supported on [this fork](https://github.com/michei69/pear-desktop) of the original app, because it uses a different theming system. While you _could_ get the CSS files and use them as-is, it is not guaranteed they will work correctly.

---

## Installation

Download this repository and extract the folder of your desired theme into the `themes` folder.

## How to Contribute

For information on how to create a theme, [click here](https://github.com/michei69/pear-desktop/blob/master/src/themes/README.md).

You can add your own custom themes to this repository by [forking this repository](https://github.com/michei69/pear-desktop-themes/fork), adding your theme folder, then [create a Pull Request](https://github.com/michei69/pear-desktop-themes/pulls) with a screenshot showcasing it.

If you are not experienced with Git/GitHub, you can also create an issue on this repository with your zipped theme folder attached.

## Expect Bugs!

The theming system is still an early addition, so expect bugs. The official frontend's classes, variables, etc. may also change over time and break themes in the process!
